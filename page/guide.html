Panduan Praktis Verifikasi Keamanan File

Panduan langkah demi langkah bagi pengguna awam maupun mahir di Windows, macOS, dan Linux—lengkap dengan cara visual tanpa koding (GUI) serta perintah terminal otomatis.

Pilih Sistem Operasi Perangkatmu: Seluruh panduan & perintah di bawah otomatis menyesuaikan pilihanmu

1. Membongkar Ekstensi Ganda & Memeriksa Segel Biner (Magic Bytes)

Jangan pernah percaya begitu saja pada ikon atau nama file di layar. File bernama Dokumen_Penting.pdf bisa saja sebenarnya adalah program .exe yang menyamar. Berikut cara memeriksa isi aslinya:

Cara Mudah Tanpa Koding (Windows Notepad / Properties):
  1. Cek Tipe Asli: Klik kanan pada file → pilih Properties. Lihat baris Type of file. Jika tertulis Application (.exe) atau VBScript padahal ikonnya PDF, jangan dibuka!
  2. Intip Segel Magic Bytes dengan Notepad: Klik kanan file → Open with → pilih Notepad. Lihat 2–4 huruf paling kiri di baris pertama: dokumen PDF asli selalu diawali huruf %PDF, sedangkan program/malware Windows diawali huruf MZ.
Cara Cepat Lewat Windows PowerShell (Membaca 16 Byte Pertama / Hex):
PS>Format-Hex -Path .\Dokumen_Penting.pdf | Select-Object -First 1
Ket: Buka PowerShell di folder Downloads (Klik kanan di area kosong folder → Open in Terminal), lalu tempel perintah di atas.
Contoh Output Jika Dokumen PDF Asli (Diawali 25 50 44 46 / %PDF): 00000000 25 50 44 46 2D 31 2E 37 %PDF-1.7
Contoh Output Jika Berisi Program .EXE (Diawali 4D 5A / MZ): 00000000 4D 5A 90 00 03 00 00 00 MZ......
Cara Mudah Tanpa Koding (macOS Finder Get Info):
  1. Klik sekali pada file di Finder, lalu tekan tombol Cmd + I (atau Klik Kanan → Get Info).
  2. Perhatikan bagian Kind (Jenis) dan Name & Extension. Jika tertulis Unix Executable, Application, atau Terminal Script padahal namanya dokumen PDF, segera hapus file tersebut.
Perintah Terminal macOS (Cek Tipe MIME & Magic Bytes):
%file -I Dokumen_Penting.pdf
%xxd -g 1 -l 8 Dokumen_Penting.pdf
Perintah Terminal Linux (Membongkar Tipe MIME & 8 Byte Pertama):
$file --mime-type Dokumen_Penting.pdf
$xxd -g 1 -l 8 Dokumen_Penting.pdf
Contoh Output Jika File PDF Asli: Dokumen_Penting.pdf: application/pdf
00000000: 25 50 44 46 2d 31 2e 37 %PDF-1.7
Contoh Output Jika Menyamar (Berisi .EXE): Dokumen_Penting.pdf: application/x-dosexec
00000000: 4d 5a 90 00 03 00 00 00 MZ......

Kamus Cepat Segel Biner (Magic Bytes Header — Berlaku di Semua OS):

Ekstensi File Kode Hex (Magic Bytes) Karakter Awal (ASCII) Status & Keterangan
.pdf 25 50 44 46 %PDF Dokumen PDF Asli
.jpg / .jpeg FF D8 FF E0 JFIF Gambar JPEG Asli
.png 89 50 4E 47 .PNG Gambar PNG Asli
.zip / .docx / .pptx 50 4B 03 04 PK.. Arsip ZIP / Dokumen Office Modern
.exe / .dll / .scr 4D 5A MZ Program Eksekusi Windows (Bahaya jika menyamar!)
ELF Binary (Linux) 7F 45 4C 46 .ELF Program Eksekusi Linux

2. Memastikan Keaslian File Unduhan dengan Sidik Jari SHA-256

Saat mengunduh installer atau tugas penting, peretas bisa saja menyisipkan trojan tanpa mengubah nama dan ukuran file. Pastikan kode SHA-256 file tersebut 100% cocok dengan kode resmi dari pengirimnya:

Cara Paling Mudah Tanpa Ketik Perintah (Drag & Drop):

Buka menu Scanner Beranda FileMate di web ini, seret file dari Windows Explorer ke kotak pemeriksaan, lalu tempel kode SHA-256 resmi untuk langsung melihat hasil pencocokan segelnya secara visual!

Cara 1: Lewat Command Prompt (CMD) Bawaan Windows (`certutil`):
C:\>certutil -hashfile .\Patch_Update_v2.zip SHA256
Cara 2: Lewat Windows PowerShell (`Get-FileHash`):
PS>Get-FileHash .\Patch_Update_v2.zip -Algorithm SHA256
Contoh Output PowerShell: Algorithm Hash Path
--------- ---- ----
SHA256 E3B0C44298FC1C149AFBF4C8996FB92427AE41E4649B934CA495991B7852B855 C:\Downloads\Patch_Update_v2.zip
Perintah Cek SHA-256 di Terminal macOS (`shasum -a 256`):
%shasum -a 256 Patch_Update_v2.zip
Contoh Output Terminal macOS: e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855 Patch_Update_v2.zip
Perintah Cek & Validasi Otomatis SHA-256 di Linux (`sha256sum`):
$sha256sum Patch_Update_v2.zip
$echo "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855 Patch_Update_v2.zip" | sha256sum -c -
Output Jika Hash 100% Cocok (Asli): Patch_Update_v2.zip: OK
Output Jika File Sudah Dimodifikasi: Patch_Update_v2.zip: FAILED

3. Pengaturan Wajib Agar Ekstensi Ganda (.pdf.exe) Selalu Terlihat

Secara bawaan, Windows dan macOS sering menyembunyikan akhiran nama file sehingga Kontrak_Magang.pdf.exe hanya terlihat sebagai Kontrak_Magang.pdf. Aktifkan pengaturan ini sekarang juga:

Cara Klik di File Explorer Windows 10 & Windows 11:
  • Windows 11: Buka File Explorer → Klik menu View di bar atas → Arahkan ke Show → Centang File name extensions dan Hidden items.
  • Windows 10: Buka File Explorer → Klik tab View di bagian atas → Langsung centang kotak File name extensions.
Trik 1-Klik PowerShell: Lacak Semua File Berekstensi Ganda di Folder Downloads:
PS>Get-ChildItem -File | Where-Object { $_.Name -match '\..+\.(exe|vbs|bat|scr|cmd|ps1)$' }
Contoh Output Jika Ditemukan Jebakan Ekstensi Ganda di Folder: -a---- 04/11/2026 13:10 1945600 Kontrak_Magang_2026.pdf.exe
-a---- 04/11/2026 13:12 28672 Form_Pengajuan_Beasiswa.docx.vbs
Cara Menampilkan Semua Ekstensi di macOS Finder:
  1. Buka Finder, lalu klik menu Finder → Settings (atau tekan Cmd + ,).
  2. Pilih tab Advanced (Lanjutan) di paling kanan, lalu centang "Show all filename extensions".
Perintah Terminal macOS untuk Mengaktifkan Tampilan Ekstensi Otomatis:
%defaults write NSGlobalDomain AppleShowAllExtensions -bool true && killall Finder
Tips File Manager Linux (GNOME Files / Dolphin / Thunar):

Linux selalu menampilkan ekstensi file secara utuh, namun peretas sering menyembunyikan script dengan awalan titik (dotfile seperti .update_miner.sh). Tekan Ctrl + H di File Manager atau jalankan perintah di bawah untuk melihat seluruh file tersembunyi:

$ls -la

4. Mengunci Izin Eksekusi File & Menyapu Flashdisk Teman

Dokumen biasa (PDF, Word, Gambar) tidak pernah membutuhkan izin untuk berjalan sebagai program (Executable). Berikut cara melucuti izin eksekusi berbahaya dan memeriksa banyak file sekaligus:

Cara Cek Pengaman "Mark of the Web" di Windows Properties:

Klik kanan file unduhan → Properties. Di bagian paling bawah tab General, jika muncul peringatan "Security: This file came from another computer and might be blocked", JANGAN centang Unblock sebelum kamu yakin 100% file itu aman!

Perintah Windows (`icacls`): Kunci File Mencurigakan Menjadi Read-Only (Cegah Eksekusi):
PS>icacls .\file_mencurigakan.pdf /inheritance:r /grant:r "$($env:USERNAME):(R)"
Cabut Izin Eksekusi & Cek Karantina Gatekeeper di macOS:
%chmod -x file_mencurigakan.pdf
%find . -maxdepth 1 -type f -perm +111
Ket: Perintah kedua langsung mendeteksi semua file di dalam folder/flashdisk yang diam-diam memiliki izin eksekusi program di macOS.
Cabut Izin Eksekusi (`chmod -x`) & Sapu Bersih Flashdisk (`find -executable`) di Linux:
$chmod -x file_mencurigakan.pdf
$ls -lh file_mencurigakan.pdf
$find . -maxdepth 1 -type f -executable
Sebelum (Berbahaya - Ada Huruf 'x'): -rwxr-xr-x 1 mhs mhs 1.9M Nov 4 09:15 file_mencurigakan.pdf
Sesudah chmod -x (Aman - Pasif): -rw-r--r-- 1 mhs mhs 1.9M Nov 4 09:15 file_mencurigakan.pdf

5. Mengintip Teks/Script Tersembunyi di Dalam File & Privasi VirusTotal

Penyerang sering menyisipkan perintah powershell, URL pencuri data, atau skrip berbahaya di dalam file gambar/dokumen. Kamu bisa mendeteksinya tanpa membuka file tersebut:

Perintah Bawaan Windows PowerShell (`Select-String` — Pengganti Strings/Grep):
PS>Select-String -Path .\Denah_Ruangan_Kantor.jpg -Pattern "http|powershell|cmd|\.exe|eval"
Perintah Terminal macOS (`strings` + `grep`):
%strings Denah_Ruangan_Kantor.jpg | grep -iE "http|powershell|cmd|\.exe|eval"
Perintah Terminal Linux (`strings` + `grep`):
$strings Denah_Ruangan_Kantor.jpg | grep -iE "http|powershell|cmd|\.exe|eval"
Contoh Output Jika Gambar Mengandung Script Malware Tersembunyi: powershell.exe -NoProfile -WindowStyle Hidden -EncodedCommand JABzAD0ATgBlAHcALQBPAGIAag...
https://malicious-c2-dropper.example.com/steal_cookie.php

Tips Privasi VirusTotal: Jangan pernah mengunggah dokumen pribadimu (kontrak, KTP, laporan) langsung ke situs pemindai publik. Gunakan Scanner Beranda FileMate untuk mengambil kode SHA-256-nya saja, lalu cek reputasi hash tersebut di VirusTotal dengan aman!

6. Prosedur Darurat Jika Terlanjur Mengklik File Malware

Apabila kamu tidak sengaja menjalankan berkas jebakan, lakukan 3 Langkah Penyelamatan Darurat ini dalam 60 detik pertama:

  1. Putuskan Internet Seketika: Matikan Wi-Fi / Mode Pesawat atau cabut kabel LAN agar infostealer gagal mengirim password & session cookies ke server peretas.
  2. Matikan Proses Mencurigakan: Ikuti langkah sesuai sistem operasimu di bawah ini.
  3. Ganti Password dari HP (Perangkat Bersih): Gunakan HP untuk mengganti password email utama dan pilih Logout from all devices.
Cara Cepat Lewat Task Manager Windows:

Tekan Ctrl + Shift + Esc untuk langsung membuka Task Manager → Cari aplikasi asing yang memakan CPU/Network tinggi → Klik kanan → pilih End task. Cek juga tab Startup Apps dan matikan (Disable) program asing.

Perintah PowerShell & CMD untuk Melacak dan Mematikan Paksa Proses Malware (PID):
PS>Get-Process | Sort-Object CPU -Descending | Select-Object -First 6 Id, ProcessName, CPU
PS>Stop-Process -Id 4812 -Force
Ket: Ganti angka 4812 dengan nomor Id (PID) proses mencurigakan yang muncul pada daftar.
Cara Cepat Lewat Activity Monitor macOS:

Tekan Cmd + Space lalu ketik Activity Monitor → Urutkan berdasarkan kolom % CPU → Pilih proses mencurigakan lalu klik ikon [ X ] (Force Quit) di bagian atas.

%ps aux -r | head -n 6
%kill -9 4812
Perintah Terminal Linux untuk Melacak & Mematikan Paksa Proses Malware:
$ps aux --sort=-%cpu | head -n 6
Contoh Output (Terlihat Proses Cryptominer/Stealer dengan PID 4812): USER PID %CPU %MEM VSZ RSS TTY STAT START TIME COMMAND
mhs 4812 94.5 2.1 412900 44120 ? Sl 13:18 1:42 /tmp/.update_dependency_miner
$kill -9 4812
